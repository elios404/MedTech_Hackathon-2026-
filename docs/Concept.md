**프로젝트 핵심 목적**

외과 수술실에서 발생하는 대량의 무오염 플라스틱 포장재가 감염성 폐기물(노란통)로 오투기되는 문제를 해결하기 위해, **의료진의 수술 집중도를 일체 방해하지 않으면서 배출부터 수거·조달까지 전 과정의 폐기물 데이터를 24/7 자동 수집하고 분석하는 3계층(3-Tier) 폐기물 인텔리전스 인프라를 구축**하는 것입니다.

* **임상 인지 부하 제로(Zero-Friction)**: 의료진에게 복잡한 분리수거 행동이나 시스템 조작을 요구하지 않고 평소대로 배출하도록 유지.


* **비파괴 데이터 측정(Regulatory Compliance)**: 호주 의료폐기물 표준(AS/NZS 3816)상 금지된 '사후 봉투 개봉' 없이 투기 시점(Tier 1)과 수거 시점(Tier 2)에서 데이터를 수집.


* **구조적 병원 프로세스 개선**: 수집된 통계를 바탕으로 수술실 내 쓰레기통 물리적 배치(Default)를 교정하고, 과대 포장된 수술 소모품 팩(CPT)을 조달 단계에서 원천 감축.



---

**3계층 세부 절차적 구현 체계**

```
[Tier 1: 수술실 배출 순간]        [Tier 2: 원내 카트 수거]           [Tier 3: 관리 대시보드]
 엣지 비전 투입구 감지    ──►     비파괴 무게·부피(밀도) 실측   ──►   원인 분석 및 프로세스 개선
 (4대 성상 및 시점 로깅)          (RFID 수술실 매핑 & 이상치)        (동선 교정 / 조달 최적화 / ESG)

```

**1. Tier 1: 수술실 내 실시간 원천 배출 감지 (Edge Vision Logging)**

* **카메라 배치**: 쓰레기통 덮개 안쪽에서 투입구(ROI) 내부만 하방(Downwards) 지향하여 환자/의료진의 신체 노출을 원천 배제.


* **4대 성상 분류 알고리즘 (Hybrid AI)**:
* `Clean_Plastic`: 비닐, 블리스터 팩, 멸균 랩, 플라스틱 트레이.


* `Clean_Paper`: 소모품 외포장 박스, 종이 매뉴얼.


* `Biohazard_Infectious`: 혈액/체액 묻은 거즈, 흡인 카테터 (HSV 색 공간 분석으로 붉은색 면적 $\ge 10\%$ 시 자동 판정).


* `Sharps_Hazard`: 메스, 주사바늘, 가위, 앰플 (최우선 위험 감지).




* **투기 이벤트 디바운싱**: 손 흔들림 등으로 인한 중복 카운트를 방지하고, 객체가 투입구를 통과해 사라지는 시점에 타임스탬프 기반 JSON 로그(`events.jsonl`)를 1회 생성.

**2. Tier 2: 원내 이송 및 물류 감사 (Smart Cart Logistics & Density Audit)**

* **비파괴 벌크 밀도(Bulk Density) 실측**:
* 미화원이 묶인 쓰레기봉투를 스마트 운반 카트에 올리면 로드셀(무게, kg)과 초음파/LiDAR 센서(체적, L)로 밀도($\text{kg/L}$)를 동시 계산.




* **양방향 이상치(Anomaly) 자동 판별**:
* **저밀도 이상치 ($\text{밀도} < 0.08\,\text{kg/L}$)**: 감염성 통에 가벼운 멸균 비닐/공기 층만 가득 찬 오투기 봉투 감지.


* **고밀도 이상치 ($\text{밀도} > 0.70\,\text{kg/L}$)**: 일반 쓰레기통에 무거운 체액/석션 통이 유출된 규정 위반(AS/NZS 3816) 위험 감지.




* **RFID 추적 바인딩**: 봉투 외부 RFID 태그를 스캔하여 배출 수술실(OT ID), 담당 진료과, 수술 케이스와 측정 데이터를 즉시 매핑.



**3. Tier 3: 엔터프라이즈 폐기물 인텔리전스 SaaS (Intelligence Dashboard)**
